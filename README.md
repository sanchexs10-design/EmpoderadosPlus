# Empoderados Plus

Landing page financiera inspirada en la identidad Empoderados Plus de Bancamía. Incluye simulador de crédito en página dedicada, presentación de beneficios y formulario de contacto en un portal separado que envía la información a hernan.sanchez@bancamia.com.co.

## Cómo usar

1. Abre `index.html` en tu navegador para ver la página principal.
2. Usa el botón **Ir al simulador** o abre `simulador.html` para estimar cuotas mensuales y totales.
3. Envía tu información desde `contacto.html`; el portal abrirá tu gestor de correo con el mensaje listo para hernan.sanchez@bancamia.com.co.
