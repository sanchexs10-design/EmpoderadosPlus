# Empoderados Plus

Landing page financiera inspirada en la identidad Empoderados Plus de Bancamía. Incluye simulador de crédito, presentación de beneficios y formulario de contacto directo a hernan.sanchez@bancamia.com.co.

## Cómo usar

1. Abre `index.html` en tu navegador para ver la página.
2. Completa el simulador para estimar cuotas mensuales y totales.
3. Utiliza el formulario de contacto o los enlaces de correo para escribir al especialista.
